# Evaluation Questions

**Project:** Beyond Full Text — AI-assisted discovery and subject indexing
of public-sector documents.

These eight questions specify criteria for later evaluation. They have
**not yet been systematically tested or scored** across all system versions.
The questions are intended to be applied consistently to the same documents
and assessed against source passages and human-reviewed reference indexing.

1. **Main topic:** Does the abstract correctly identify the document's
   principal purpose (EU international partnerships) rather than a minor topic?
2. **Key initiatives:** Does the abstract correctly describe the role of
   Team Europe and Global Gateway without introducing unsupported claims?
3. **Numerical accuracy:** Does the system report the 42% global ODA
   share with its reference year (2023) when that claim is included?
4. **Investment target:** If the Global Gateway target is mentioned,
   does the system distinguish the aim to mobilise *up to*
   EUR 300 billion by 2027 from money already invested?
5. **Evidence:** Can each important factual statement in the
   abstract be traced to an identifiable passage in the document?
6. **Authority validity:** Does each proposed GND heading have
   the exact preferred label and identifier of a retrieved GND record?
7. **Subject relevance:** Is each selected GND heading a central
   subject of the document rather than a superficial association
   (e.g. religious aid or the Clean Development Mechanism)?
8. **Topical coverage:** Do the chosen headings adequately represent
   the document's central themes without redundant or irrelevant terms?

## Planned evaluation procedure

- Apply the same questions to each relevant system version.
- Record the output and source evidence for each question.
- Evaluate summaries and subject indexing separately where necessary.
- Use a human-reviewed reference as a comparison, not just model judgment.
- Record unsupported claims, omissions, incorrect GND mappings,
  and semantically unsuitable headings.
- Where questions are inapplicable to a version (for example, GND
  questions for a pure summarization baseline), record **N/A**
  instead of treating them as failures.

## Current status

Question set drafted on 24 November 2026.
Systematic scoring has not yet been performed.
